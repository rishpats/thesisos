## 1. Classification Legend

* **Category A — Required and Free:** No mandatory payment, no credit-card requirement, no paid billing triggers, and no external API credential required for core runtime operation. Only Category A components may be mandatory runtime dependencies.
* **Category B — Optional Free Service:** Applicable free tier exists without mandatory payment, but carries usage quotas, rate limits, data-training trade-offs, or changing terms. Offered strictly as an opt-in enhancement (such as Bring-Your-Own-Key LLM synthesis) with a complete Category A deterministic fallback.
* **Category C — Not Suitable:** Requires payment, requires a credit card that can incur charges, violates data redistribution terms, exceeds free hosting memory/CPU limits, or lacks a reliable deterministic fallback. Excluded from mandatory runtime architecture.

## 3. Critical Architectural Findings from the Stress Test

1. **Memory Ceiling Protection (Streamlit 2.7 GB Limit):** Streamlit Community Cloud enforces a hard **2.7 GB RAM limit** (and practical headroom is closer to ~1.8–2.0 GB after the Python and Streamlit runtime overhead). Installing `torch`, `sentence-transformers`, or `chromadb` in the initial public app frequently causes silent out-of-memory (OOM) container kills. Therefore, `scikit-learn` TF-IDF + exact financial keyword matching is our mandatory Category A retrieval engine.
2. **Container Hibernation ("The 12-Hour Sleep Rule"):** Free Streamlit Community Cloud apps hibernate after roughly 12 hours of zero traffic. When a recruiter clicks the link on a sleeping app, they see a *"Yes, get this app back up!"* button that takes 20–40 seconds to boot. To make this boot nearly instantaneous (<5 seconds), our app must **never download models or scrape websites at startup**—all demo company financial facts (`financial_facts.csv`) and pre-extracted filing chunks will load directly from lightweight, cached local CSV/JSON files using `@st.cache_data`.
3. **Open-Source License Compatibility (`PyMuPDF` AGPL-3.0 vs `pypdf` BSD):** Artifex licenses `PyMuPDF` (`fitz`) under **GNU AGPL-3.0**. Using `PyMuPDF` in a publicly hosted web app is 100% free **provided your public GitHub repository is also licensed under AGPL-3.0**. If you prefer to license your portfolio code under the permissive **MIT License**, we can either license the repo as AGPL-3.0 or use `pypdf` (BSD-3-Clause) + `pdfplumber` (MIT) so every dependency is MIT/BSD/Apache-2.0 permissive.
4. **Lawful Indian Financial Data Strategy:** Under the [NSE Data Sharing & Usage Policy](https://www.nseindia.com/static/market-data/nse-data-policy), redistributing live exchange price feeds without a commercial license is prohibited, and unofficial scrapers (`yfinance`, `nselib`) break frequently on cloud IPs. ThesisOS solves this lawfully and reliably by combining:
   * **Manually verified historical annual financial facts** sourced from official published Annual Reports (with exact PDF page numbers and URLs recorded per line item).
   * **Explicit Dated Reference Market Price inputs** where the user or demo preset supplies a dated closing price (clearly labeled as a *Dated Reference Price*, never falsely presented as a live exchange ticker).
5. **Zero-Key Recruiter Experience:** Recruiters visiting your public URL will immediately experience a complete, institutional-grade research terminal for our verified flagship Indian non-financial company (e.g., **TCS Ltd.**), complete with 5-year financial statements, ratio diagnostics, forensic alerts, interactive DCF valuation & sensitivity matrices, annual report passage search with page citations, and both a **Rule-Based Deterministic Research Memo** and a **Pre-Verified Example AI Dossier**—all with **zero API keys required**.
